# Sepehr Meeting — اجرای لوکال

## اجرا

روی فایل **`Start-Sepehr-Meeting.bat`** دوبار کلیک کنید.

- اگر سرور از قبل روشن باشد، فقط مرورگر باز می‌شود.
- در غیر این صورت سرور روی `https://localhost:3010` بالا می‌آید و مرورگر خودکار باز می‌شود.
- پنجرهٔ Command Prompt باید **باز بماند**؛ بستن آن یعنی خاموش شدن سرور.

> بار اول ممکن است مرورگر هشدار گواهی (self-signed) نشان دهد:
> **Advanced → Proceed to localhost (unsafe)** را بزنید.

اجرای دستی (معادل):

```powershell
cd C:\sdq\meet\Sepehr-Meeting
node app/src/Server.js
```

## تست سریع

1. صفحهٔ اصلی باز شود (`https://localhost:3010`).
2. «شروع یک جلسه» → ساخت اتاق.
3. در تب دوم مرورگر همان لینک اتاق را باز کنید تا دو نفر شبیه‌سازی شوند.
4. ورود با نام نمایشی، سپس تست: میکروفون، دوربین، اشتراک صفحه، چت، نظرسنجی، تنظیمات.

## توقف

در پنجرهٔ Command Prompt کلید `Ctrl+C` را بزنید.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `node` شناخته نمی‌شود | Node.js 24.x نصب نیست؛ از nodejs.org نصب کنید |
| پورت 3010 اشغال است | `netstat -ano \| findstr :3010` و پروسهٔ قبلی را ببندید (یا از خود لانچر استفاده کنید) |
| دوربین/میکروفون کار نمی‌کند | دسترسی مرورگر را Allow کنید؛ `localhost` امن محسوب می‌شود |
| صفحهٔ سفید | `Ctrl+Shift+R` و بررسی کنسول مرورگر (F12) |
| قطع‌وصلی صدا/تصویر | پورت‌های UDP 40000–40100 و مقدار `ANNOUNCED_IP` در `.env` را بررسی کنید |

## نکتهٔ فنی

نسخهٔ فعلی صفحهٔ اتاق (`public/views/Room.html` و اسکریپت‌های `Room.js` / `RoomClient.js`)
نسخهٔ پایهٔ سالم است؛ متن‌های فارسی از `public/lang/fa.json` و برند از `public/js/Brand.js` اعمال می‌شوند.
